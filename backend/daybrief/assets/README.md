# Canonical DayBrief cat anchor

`anchor_neutral.png` is the single canonical `daybrief-cat-v1` newsroom asset.
Created once with the built-in imagegen tool (generate mode), then bundled with
DayBrief. Runtime planning makes no image-model calls. Every scene references the
same SHA-256-addressed copy. This is a fictional presenter, not documentary imagery.

Final generation prompt:

> Use case: stylized-concept. Asset type: one canonical reusable 16:9 landscape cartoon newsroom anchor image for the DayBrief application. Create a friendly professional adult-proportioned cartoon cat news anchor seated behind a simple modern curved newsroom desk. Clean sophisticated 2D editorial illustration with soft dimensional shading, not photorealistic, cute but not childish or meme-like. Character identity: warm grey fur with cream muzzle and inner ears, restrained attentive green eyes, navy blazer over a plain light neutral shirt, no patterns or logos, calm small closed-mouth smile. Consistent recognizable face and proportions. Upper body and paws visible, looking directly at camera. Cat centered with generous safe margins around ears and shoulders, face prominent enough to remain readable in a picture-in-picture panel. Restrained modern blue and neutral newsroom set, soft studio lighting, simple geometric back panels without screens containing news or maps, subtle depth, no implied real news event. Desk occupies lower quarter. Polished broadcast illustration. No embedded text, letters, numbers, watermark, brand marks, charts, logos, microphones obscuring face, other characters, dramatic expressions, photo-realistic fur, or human anchor. Full-frame composition 16:9.

Replace this asset deliberately and bump the style ID when changing the design.
No independent per-story character generation is used. Talking/blinking poses
can be added later as controlled derivatives of this canonical image.
