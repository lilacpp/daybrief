# Blink poses

Generated once with the built-in imagegen tool using each canonical character as
its reference. Original artwork is unchanged. Only feathered eye regions from
these poses are used in animation; the rest of the generated image is discarded
by the renderer. No runtime image generation is needed.

Files: `cat_blink.png`, `dog_blink.png`, `fox_blink.png`.

Cat/Dog prompt: Precise local edit for a cartoon animation sprite. Change ONLY
both eyes to gently and naturally closed eyelids during a calm blink, thin clean
curved eyelash lines, relaxed rather than laughing. Preserve eyebrow positions,
face outline, fur colors, muzzle, closed mouth, proportions, clothing, paws,
desk, background, dimensions and framing. No new text.

Fox prompt: Edit only the two eyes into relaxed closed eyelids for a calm blink.
Preserve the exact character, eyebrows, mouth, face proportions, clothing,
background, framing and dimensions. No smile change or other changes.
Canonical animation blink pose.
